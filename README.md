# Hands of Our World

A p5.js + ml5.js HandPose interactive media artwork with a landing page,
five-step tutorial, language switcher, and in-experience help.

## Local Preview

Run a local static server from this folder, then open the URL in Chrome or Edge.
Camera access works best in a real browser, not an embedded preview browser.

```powershell
python -m http.server 8051 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8051/
```

## GitHub Pages

This project is a static site. Publish the folder contents to a GitHub repository
named `hands-of-our-world`, then enable GitHub Pages from the repository settings.
